Aula 3 · 15 min

Canal chat: o seu agente numa página web

O terminal é um canal; uma página de chat é outro. A caixa é a mesma: só muda a porta por onde o pedido entra. Nesta aula o agente ganha uma página no seu navegador, com a trilha das peças embaixo de cada resposta.

Começar a aula

Nesta aula você vai

  1. 1Um canal novo sem mexer na caixa
  2. 2Como a página conversa com o seu computador
  3. 3Por que a porta muda a cada vez

Objetivo: abrir o chat do agente no navegador, mandar um pedido e ver a resposta com a trilha [canal chat] e [cérebro …].

Você está aquias peças acesas são as desta aula

Clique em cada bloco do diagrama para ver o que ele faz.

01 · Uma porta nova, a mesma caixa

Clique em Próximo passo.

02 · Ligue o chat

O terminal fica ocupado com o servidor. Abra o endereço que aparecer; Ctrl+C desliga.

Terminal · ligar o chat
cd ~/agente-por-pecas-kit && git checkout -q aula3
python3 canal_web.py

03 · Testar sem o navegador

O mesmo pedido que a página manda, feito por um comando. Útil para conferir se o canal está de pé.

Terminal · testar o canal chat
cd ~/agente-por-pecas-kit && git checkout -q aula3 && rm -f web.url
python3 canal_web.py > chat.log 2>&1 & CHAT=$!
until [ -s web.url ]; do sleep 0.3; done
python3 -c "import json,urllib.request; u=open('web.url').read(); r=urllib.request.urlopen(urllib.request.Request(u, json.dumps({'texto':'Diga oi em 3 palavras'}).encode())); print(json.loads(r.read()))"
kill $CHAT; cat chat.log
Exemplo do repositório
{'resposta': 'Oi, tudo bem?', 'trilha': ['[canal chat] Diga oi em 3 palavras', '[cérebro gpt-6-luna] respondeu']}
chat no ar: http://127.0.0.1:<porta>/
[canal chat] Diga oi em 3 palavras
[cérebro gpt-6-luna] respondeu

A porta (127.0.0.1:<porta>) muda a cada vez: o sistema escolhe uma livre.

04 · Prática: converse pelo navegador

Faça na ordem.

E1 · O chat no ar

5 min

Rode o bloco Ligar o chat e abra o endereço no navegador.

Pronto quando: a página "Chat com o meu agente" abre e o terminal mostra chat no ar: http://127.0.0.1: e um número.

E2 · Um pedido seu

5 min

Mande um pedido pela página (por exemplo, "me dê 3 ideias de almoço").

Pronto quando: aparece o balão da resposta e, embaixo, a trilha com [canal chat].

05 · Teste o que aprendeu

A explicação aparece depois da sua resposta.

Pergunta 1 de 4

O que mudou na caixa para o agente atender pelo chat?

Pergunta 2 de 4

Por que o endereço do chat muda a cada vez que você liga?

Pergunta 3 de 4

A página mostrou a resposta mas não a trilha. Onde olhar primeiro?

Pergunta 4 de 4

Quem pode abrir o seu chat local, do jeito que ele está?
